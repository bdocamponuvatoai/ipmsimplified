# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to [contact@ipmsimplified.com](mailto:contact@ipmsimplified.com). Include the affected URL or component, reproduction steps, impact and any supporting evidence.

Do not include sensitive personal information and do not test against data or accounts you do not own. Please allow a reasonable period for investigation and remediation before public disclosure.

## Supported version

The latest commit on the default branch is the supported website release. Production dependencies are audited as part of the release workflow.
